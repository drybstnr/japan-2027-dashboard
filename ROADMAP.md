# Roadmap

## Sprint 1 — Dashboard
### Goal
Establish the core product shell and travel overview for the trip.

### Key deliverables
- Dashboard summary layout
- Trip countdown and route overview
- Weather and travel context blocks
- Mobile-first card system

### Success criteria
- Users can quickly understand the trip status at a glance.
- Dashboard feels premium and polished on mobile.

## Sprint 2 — Interactive Itinerary
### Goal
Turn the trip into an editable, granular planning surface.

### Key deliverables
- Day-by-day itinerary cards
- Expand/collapse planning states
- Add plan flow
- Persistence for itinerary state and drafts

### Success criteria
- Users can add and revisit daily plans without losing progress.
- Itinerary flow feels smooth and native.

## Sprint 3 — Explore
### Goal
Support discovery and trip inspiration with curated experiences.

### Key deliverables
- City-based exploration views
- Saved items and plan-ready experiences
- Reusable experience cards and actions

### Success criteria
- Users can discover places and move them into planning quickly.
- Explore content remains consistent with the travel narrative.

## Sprint 4 — Food
### Goal
Provide a premium restaurant discovery and planning flow.

### Key deliverables
- Search experience for restaurants, cafés and bakeries
- Native-feeling cards and detail sheet
- Save and add-to-day actions
- Reusable place model

### Success criteria
- Users can find relevant food options without leaving the app.
- Food search fit the product language and planning flow.

## Sprint 5 — Community
### Goal
Support collaborative travel ideas and recommendations.

### Key deliverables
- Suggestions flow
- Review and save patterns
- Add-to-day handoff
- Light community-friendly planner interactions

### Success criteria
- Idea sharing feels clean and does not overload the itinerary prematurely.
- Users can review suggestions before turning them into plans.

## Sprint 6 — Live Place Search
### Goal
Add premium in-app place search for the broader product.

### Key deliverables
- Search provider abstraction
- Place details sheet
- Mini map preview
- Reusable search components

### Success criteria
- Search feels native and in-app, not like a generic website.
- Place objects can be reused across planning surfaces.

## Sprint 7 — Supabase Collaboration
### Goal
Move from local persistence to shared collaborative data.

### Key deliverables
- Supabase setup
- Shared trip state
- Auth and session handling
- Reliable multi-user planning sync

### Success criteria
- Planning can scale beyond a single-device local flow.
- Collaboration is stable and predictable.

## Sprint 8 — Memory Mode
### Goal
Enhance the product as a long-term travel companion and memory layer.

### Key deliverables
- Trip memory and recap surfaces
- Recommendations based on completed itinerary items
- Reflection and journal-like travel moments

### Success criteria
- The product remains useful before, during and after the trip.
- Users can revisit and relive key travel moments.
