## v0.2 — MVP Foundation & Planning UX
Date: 15 September 2026

### Highlights
- Project foundation completed.
- Dashboard MVP completed.
- Interactive itinerary foundation completed.
- Local persistence implemented.
- Apple-inspired design direction locked.
- Final Japan route established for the 2027 trip experience.

This release focuses on establishing the product foundation for a premium travel planner experience. The dashboard and interactive itinerary now provide the core planning surface, and persistence ensures user actions are retained across refreshes. The design language remains aligned with the Apple-inspired product direction set in the project rules.
